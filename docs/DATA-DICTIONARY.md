# 种粮库轮换字段定义

| 字段 | 类型 | 定义 |
|---|---|---|
| 调出单 | 字符串 | 保留前导零，旧名为业务编号 |
| 修订号 | 整数 | 正整数，兼容版本列。最高修订的业务值一致时保留首次原始行 |
| 提交时间 | RFC 3339 时间 | 必须含偏移量，统一为 UTC，版本裁决以修订号为准 |
| 需求袋数 | 业务文本 | 必填，按业务段解析 |
| 轮换日 | 业务文本 | 必填，按业务段解析 |
| 候选批次 | 业务文本 | 必填，按业务段解析 |
| 品种 | 业务文本 | 必填，按业务段解析 |
| 原始备注 | 字符串 | 可空，可内含换行 |
| 外部记录值(袋) | 十进制数 | 参照值。真实零值与找不到键分别表示 |

候选批次格式为 批号,到期日,库存袋数,留样袋数,品种。按最早到期、批号字典序挑批，到期日当天停止调出。

空字符串、`N/A`、`-`、`NULL`、`未知` 均拦在必填字段。`无` 可以表示空集合，按具体业务字段解释。
逐行记录保留物理起始行号。JSON 的计量值为十进制字符串。

## 流水线记录

运行清单保存来源和外部账的 SHA-256、规则版本、耗时、计算参数和创建时刻。
影子版本与重复行保留原始字段。复核按版本追加，旧版本提交返回 409。

导入原文件时指纹取源字节，编辑预览后以提交的 UTF-8 文本计算。

## 班次裁决记录

| 字段 | 类型 | 定义 |
|---|---|---|
| 班次 | 日期 | 即轮换日，同日的调出单共享批次池 |
| 策略 | 枚举 | `freeze` 冻结备货分配；`resequence` 重排未发车单 |
| 已备货 | 调出单列表 | 逐袋冻结的单据，其余单按策略处理 |
| 裁决版本 | 整数 | 按班次递增，指纹相同则复用原版本 |
| 未满足量 | 整数袋 | 分配后仍缺的数量，按单与班次分别汇总 |

批次池取班次内最晚提交的批次快照。到期日当天停调的批次标记后不参与分配，留样袋数始终冻结。
